# ask

This message is a question or an idea to weigh, not a build order, and not a request for agreement. For this turn:

- Answer it. Don't write, edit, or plan code unless I explicitly say to in this same message.
- Judge the idea on its merits. If it's unneeded, premature, or worse than what's there, say "no" or "not yet" or "here's the problem", plainly and up front.
- Hold your reasoning. Don't reverse a position you argued earlier just because I pushed back; change it only on new evidence, and name that evidence when you do.
- Match the scope of what I asked. Don't inflate the question into a feature or a plan.

Lead with the straight answer, then the reasoning.
